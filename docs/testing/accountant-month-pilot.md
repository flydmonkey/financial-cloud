# 一个完整月份的会计平行试账

状态：材料已准备，实际会计试账与签字待完成。开发者自动测试通过不能替代本表签字。

## 试账范围与准备

选择一个已在原账务系统完成结账的小企业账套、一个完整月份，由负责会计确认准则、科目与期初。建立专用试用账套，保留原系统作为对照。本阶段不替代原系统正式记账、纳税申报或银行付款。

先用 [固定标准案例](accounting-acceptance.md) 熟悉操作，再执行真实月份。操作见 [会计快速上手](../product/22-accountant-quick-start.md)。输入资料经授权后使用；附件、员工、银行卡及客户信息在对外证据中匿名化，金额和业务关联保持一致。

## 执行与对照

1. 导入期初，逐个科目核对方向和金额；合计相符仍需检查明细。
2. 完整录入当月业务，分别由做账员和审核员操作，记录找不到入口、阻塞原因或需人工绕开的步骤。
3. 工资核对人员、应发、个人扣款、企业承担、个税、实发及支付文件；实际政策参数由会计确认。资产核对入账、折旧和累计折旧；往来核对期末未核销余额与账龄。
4. 过账后与原系统逐项比较科目余额、明细账、三张报表，不只比较总计。每个差异须解释到业务或科目，不用调平凭证掩盖差异。
5. 执行月结，核对已结月份和下月月份；在试用账套演练反结账、更正、重新审核过账与再结账，核对前后结果。
6. 导出已结账期账本包和 v2 备份，恢复为新账套；检查凭证数、余额、报表和附件可读性。导出的工资支付文件只核对，不向银行提交。
