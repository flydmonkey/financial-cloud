## 缺陷

### BUG-TZ-DATE（P0）
开放账期首日 `2026-01-01` 暂存报「已结账期间…」；`2026-01-15` 正常。疑 UTC 边界。

### BUG-CF-UI-SIGN（P1）
UI 指定抽屉需负金额才能过平衡校验，报表流入显示为负。API 正数指定与 UI 不一致。2 月脚本注入 CF 时「无待指定非现金行」WARN，现金表未按文档逐项复核。

### OBS-UNAUDIT-TO-REVIEWING
反过账后再反审核进入「审核中」，需「撤回审核后修改」。

### OBS-CARRY-STALE-POINTER / 重复生成
删除结转凭证后 `settlement_carryforward` 残留；向导/脚本多次「生成并过账」可产生重复收入结转。本测已反过账删除重复件并整理断号。
