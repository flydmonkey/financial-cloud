# 会计操作手册：建账到月末交付

适用于小微企业会计与小型代账团队。首页「做账指引」按以下五段提供已有页面入口；没有入口时联系账套管理员授权。指引是操作说明，不是业务完成状态。

## 1. 建账与检查

首次登录按初始化向导建账；已有账套从「账套管理」检查企业名称、准则、启用月份与审核开关。进入后核对顶栏账套和当前账期，再进行后续操作。启用审核时安排另一位审核人并授予当前账套权限。

## 2. 导入期初

进入「基础设置 → 初始余额」，先下载模板，按末级科目编码填写。导入后核对借贷总额及银行、往来、资产等余额；使用中途启用账套时同时核对年初与累计发生额。录入业务凭证前完成期初检查。格式或编码报错时修正原表后重试，不重复创建已有科目。

## 3. 日常做账

在「录凭证」逐张录入，或在「凭证列表」按模板导入。核对日期、字号、摘要、科目、辅助单位、金额和附件。启用审核时依次提交→由另一位审核人审核→过账。制单人不能审核自己的凭证；被拒绝凭证先修改并重新提交。核对「明细账」中的发生额与凭证。

出纳、资产、薪资、报销等生成的凭证，也要核对是否已生成、审核和过账，避免手工重复记账。

## 4. 月末结账

从首页指引或待办直接进入「月结」向导：

1. 人工确认：核对银行、存货等本期业务；适用项完成后勾选确认。
2. 凭证整理：处理未过账、被拒绝凭证与断号。需要审核的凭证由其他审核人处理后刷新。
3. 计提与结转：完成应折旧资产计提，以及本期损益结转生成并过账。无对应余额时显示不适用。已有结转后又新增业务，检查是否需要补充结转。
4. 系统校验：阅读失败原因及处理建议；点击「去处理」。往来项进入账龄分析核对明细与核销，返回后重新检查。未知检查项按说明找管理员排查。请求失败或无检查结果不允许进入结账。
5. 结账：通过校验后确认执行。成功页显示刚结完的账期；当前开放账期推进到下月。刷新失败提示不表示账务结账失败，不要因此重复结账。

若发现上月错误，进入「结账列表」，仅最近已结月份符合条件时可反结账。下月已有业务可能阻止反结账。反结账后核对修改、重新生成必要结转并重新检查，不能沿用之前的检查结果。

## 5. 核对与交付

结账成功后点「核对本期报表」，资产负债表会选择刚结完的月份；再查看同月利润表、现金流量表和账簿。资产负债表差额必须排查，不能通过修改总计调平。核对完成可从该资产负债表页点「交付所选账期」，直接进入导出窗口，无需返回月结向导。

点「交付本期账本包」，导出窗口自动选择刚结完的月份。普通结账列表的导出默认当前开放月份的上一月，可自行改为其他已结月份；尚未结账的月份不能视为已完成交付。确认账期与企业，再导出并核对包内文件。

账本包用于报表交付，与完整数据备份不同。备份附件与跨实例恢复能力仍以现有备份边界说明为准。

## 试用验收

先按 [账务可信验收包](../testing/accounting-acceptance.md) 跑标准案例，再由会计按手算答案填写签字表。真实账期试用、人工核对与正式部署分别记录；测试通过不替代会计签字。
