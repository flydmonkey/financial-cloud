# 固定资产模块 — 全面测试计划

> 日期：2026-08-30  
> 范围：类别 / 卡片 / 购入凭证 / 计提与重提 / 加速折旧 / 暂停恢复 / 清理 / 变动 / 明细·汇总报表 / 复制·导入导出 / 菜单与体验打磨  
> 账套建议：E2E账套；账期 `2026-08`；演示数据：`python tools/seed_fixed_asset_demo.py`

## 1. 测试目标与通过标准

**目标**：验证固定资产端到端业务闭环正确、规则与规格一致、错误提示可理解、凭证可追溯。

**通过标准（建议）**：

| 级别 | 要求 |
|------|------|
| P0 阻断 | 全部通过；无数据错账、无凭证借贷不平、无状态机死锁 |
| P1 高优 | ≥95% 通过；剩余有记录且有规避方案 |
| P2 体验 | 记录问题即可，不阻断发版 |

**退出准则**：P0 全绿；核心折旧金额抽检与手工验算一致；清理/购入/折旧三类凭证均可从卡片或计提页跳转打开。

## 5. 规则专项（必测，与金额相关）

以下用**新造小金额资产**便于手工验算（避免依赖演示卡历史累计）。

### 5.1 起停提

| 规则 | 用例要点 |
|------|----------|
| 当月增当月不提 | 账期 M 新建，M 计提不含；M+1 含 |
| 当月减当月照提 | M 月清理前先计提（或清理后仍算入 M）；M+1 不含 |
| 暂停自所属期停 | `suspended_period=M` → M 及以后不含 |

### 5.2 重提安全

| 凭证状态 | 重提 |
|----------|------|
| 草稿/未审核 | 允许，旧凭证删除 |
| 已审核或已过账 | 禁止 |

### 5.3 加速寿命

合法：24/36/48/60…；非法：12、18、30、null。

### 5.4 凭证平衡

每次购入/折旧/清理后打开凭证：借贷合计相等；科目与卡片配置一致。
