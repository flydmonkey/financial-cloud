# Proposal: 代账专业可用收口

## Why

自主迭代验收条已满足，队列仅剩 Non-goal / 需计价的延后项。需一次性对齐产品文档与 backlog，正式关闭「代账专业可用」程序，避免文档仍写「未做」造成误判。

## What Changes

- backlog：标记程序 **已完成 / 队列关闭**；后续项归入 Post-V1 / Non-goal。
- overview / statement / gap / roadmap / 07：老板极简以首页承接结案；PDF 与备份/日记账回写等近端状态对齐。
- 明确不做：税局直连、工资条自助、移动端/AI、盘盈无计价自动入账、独立参数中心（P2 延后）。
