| 标记 | 含义 |
|------|------|

每条格式：**PRD 要求** → **代码现状** → **结论** → **证据** → **优先级（仅缺口）**

## 10. 代码已有、建议补进 PRD 的能力

以下能力在仓库中已实现或接近商用，但原 PRD V1.0「八大模块」未写或仅放在更晚版本：

| 能力 | 现状摘要 | 建议 |
|------|----------|------|
| 出纳日记账 | 账户/流水/汇总/生成凭证/结账联动 + 银行对账与余额调节表（`JournalReconciliationService`） | 升为 V1.0 正式模块 |
| 薪资与个税 | 员工、算薪、社保、计提发放凭证 | PRD 标为 V1.2，实际可前移为已交付 |
| 反结账 | 守卫 + 事务回滚 + 日记账期初恢复 | 写入结账章节 |
| 会计准则双模板 + 报表规则可配置 | 建账复制 + rules 种子 | 写入基础设置亮点 |
| 凭证录入工作台（留页/邻证/WYSIWYG） | OpenSpec 已完成 | 更新凭证原型说明 |
| 经营仪表盘指标集 | 资金/应收/利润/增值税等 | 明确是否替代「老板极简报表」 |
| 机构（institutions）域名品牌 | 配置页 + Filter | PRD 标注为部署项，非完整多租户 |

## 11. 优先级汇总（缺口补齐建议）

### P0（代账合规与交付刚需）——已全部清零

1. ~~往来管理最小闭环（余额/明细/对账/账龄）~~ → **已落地 L1+L2**；剩余 **核销 L3** 见 P1  
2. ~~**账套/数据备份与恢复**~~ → **已落地**（`openspec/changes/book-backup-restore`：账套级备份包导出 + 克隆式恢复；定时备份与覆盖式恢复为后续增强）  
3. ~~**本月账本包 ZIP**~~ → **已落地**（`openspec/changes/daizhang-commercial-plan`）

### P1（体验与合规打磨）

1. ~~**往来核销 L3**（开项匹配）~~ → **已落地**  
2. ~~明细账凭证号溯源；报表关键数字下钻~~ → **已落地**（`StatementDrillService` + 明细账超链）  
3. ~~经典凭证打印模板接入生产入口~~ → **已落地**（编辑页 + 列表批量打印）  
4. ~~制单人 ≠ 审核人；往期锁定补齐新建凭证~~ → **已落地**  
5. ~~首页待办；业务操作日志 + IP~~ → **已落地**  
6. ~~凭证附件文件~~ → **已落地**；老板报表定位确认（首页看板即定位，不再做单页）  
7. ~~账套封存态~~ → **已落地**（status=2 归档只读 + BookSealGuard 写拦截）

**P1 已全部清零。**

### P2（增强）

1. ~~多栏账 / 数量金额账~~ → **已落地**（`MultiColumnLedgerService`、`QuantityLedgerService`）  
2. ~~资产盘点~~ → **已落地**（`FixedAssetCheckService`；盘点凭证为后续增强）  
3. PDF 导出与打印统一（账簿/报表/盘点表均已接入浏览器打印另存 PDF（`tablePrint.ts`），服务端统一 PDF 通道为后续增强）  
4. ~~作废/拒绝状态机产品化~~ → **已落地**（作废/恢复 + 字号保留 + 期间/封存守卫）  
5. ~~银行调节~~ → **已落地**（`JournalReconciliationService`：对账单余额登记 + 流水勾对 + 未达账项调节）；~~税务申报~~ → **申报底稿已落地**（`TaxDeclarationService`：增值税及附加税费申报表简版主表，按官方行次 + 可打印，正式税局直连仍为 Non-goal）；~~费用报销~~ → **已落地**（`ExpenseClaimService`：报销单（单头+多行费用明细）暂存→提交→审核/拒绝→一键生成报销凭证（逐行借方+合计贷方），票据附件影像（`ExpenseClaimAttachmentService`，复用 file_storage，暂存/已拒绝可增删、下载不限），挂「凭证」组）

## 12. 覆盖率粗估（相对 PRD V1.0 八大模块）

| 模块 | 粗估覆盖 |
|------|----------|
| 账套 | ~80% |
| 基础设置 | ~85% |
