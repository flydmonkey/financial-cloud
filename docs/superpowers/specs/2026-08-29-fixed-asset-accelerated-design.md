# 固定资产加速折旧（双倍余额递减 / 年数总和）

## 范围

在现有直线法、工作量法、不计提之外，增加：

- `DOUBLE_DECLINING` 双倍余额递减法
- `SUM_OF_YEARS` 年数总和法

口径：**按年计算、月均摊**（准则常用）；DDB **最后两年转直线**。

## 年限约束

沿用 `usefulLifeMonths`：

- 须 `>= 24` 且能被 `12` 整除
- `N = usefulLifeMonths / 12`
- 不满足时：卡片保存可提示；**计提时对该卡报错**（错误码提示改方法或年限）

## 双倍余额递减

- 年折旧率 `r = 2 / N`
- 折旧年度 `year = floor(depreciatedPeriods / 12)`（从 0 起）
- **前 `N-2` 年**：用模拟得到该年年初净值（原值−减值−此前各年年折旧）；年折旧 = 年初净值 × r；月折旧 = 年折旧 / 12
- **最后 2 年**：月折旧 = remaining ÷ 剩余月数；最后一期补差提足
- 任一月 `min(计算值, remaining)`；`remaining≤0` 则 0

## 年数总和

- `S = N(N+1)/2`
- 第 `year` 年（0 起）：年折旧 = (原值−减值−残值) × `(N−year) / S`
- 月折旧 = 年折旧 / 12；最后一期补差；不超过 remaining

## 接入

- `FixedAssetDepreciationRules` + 单测
- `DepreciationMethod` 枚举；计提 `calcAmount` 分支
- 类别 / 卡片 / 变动下拉；选中后仍显示预计使用期数
- 变动后只影响后续期（既有）

## 不做

- 纯按月双倍
- 不足整年的特殊摊销
- 历史折旧回溯重算
