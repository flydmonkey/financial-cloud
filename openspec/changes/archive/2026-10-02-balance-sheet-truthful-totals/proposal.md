## Why

资产负债表非严格模式在不平时改写负债及权益总计，掩盖真实差额，导致总计与明细不一致。应保留原始计算结果并明确展示异常。

## What Changes

- **BREAKING** 非严格模式不再自动调平总计；API、打印、Excel、PDF 保留实际结果。
- API 返回期末试算平衡状态和差额，页面显示不平提示。
- 保留严格模式错误码和一分钱容差；补充正负差额、容差及严格模式回归。
- 同步 CI 注释、相关测试与产品文档，记录验证结果。
- 用户要求继续处理真实复跑差额：修正小企业研发支出科目规则、阻止旧结转后仍有余额的结账、支持补充结转及收入/费用冲回。
- 用户后续授权全模块账套隔离审计及修复：修复未授权切换、旧授权提权、对象/批量/关联 ID 越界、配置搬迁和文件旁路，补充隔离库回归。

## Capabilities

### New Capabilities
- `balance-sheet-integrity`: 资产负债表真实总计与可见勾稽差额。
- `book-isolation`: 会话账套资格、对象归属、关联和批量操作、文件对象及全局管理权限。

### Modified Capabilities
无。

## Impact

影响资产负债表服务、响应 DTO、报表页面、结转服务与页面、相关单测及 E2E 断言。后续授权的隔离修复影响认证、权限、业务控制器、文件及导入服务。无表结构变更和新增依赖；已有小企业账套的研发取数规则提供幂等修复 SQL。
