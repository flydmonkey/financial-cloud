## 缺陷

### BUG-TZ-DATE（P0）

- **前置**：账套开放账期 2026-01，凭证日期 UI 显示 `2026年01月01日`
- **步骤**：新增凭证 → 日期为当期首日 → 暂存
- **预期**：允许暂存
- **实际**：`已结账期间不允许新增或修改凭证（当前开放账期 2026-01）`
- **对照**：同账套改为 `2026-01-15` 后暂存成功
- **影响**：开放账期第一天无法做账；自动化/跨时区环境必现
- **推测**：`2026-01-01 00:00:00+08` 按 UTC 格式化成 `2025-12`，触发 `currentTerm > voucherTerm`

### BUG-CF-ZERO（P1，或测试缺口）

八笔含多笔现金业务且已过账，现金流量表经营/投资/筹资明细仍为 0。录入脚本未稳定完成「现金流指定」UI；需产品确认无指定时是否应阻断过账。

### OBS-5602-LEAF

`5602 管理费用` 非末级（15 个子目），必须选叶子（本测用 `5602.01`）。
