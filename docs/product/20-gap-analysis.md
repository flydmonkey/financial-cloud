# 20 · 与 PRD 差距分析

> 对照文档：《小微企业财务软件产品需求文档（带原型完整版）》V1.1

> 优先级：按**代账 / 小微合规交付**业务价值分级（非纯工程难度）

## 图例

| 标记 | 含义 |
|------|------|

## 10. 代码已有、建议补进 PRD 的能力

以下能力在仓库中已实现或接近商用，但原 PRD V1.0「八大模块」未写或仅放在更晚版本：

| 能力 | 现状摘要 | 建议 |
|------|----------|------|
| 出纳日记账 | 账户/流水/汇总/生成凭证/结账联动 | 升为 V1.0 正式模块 |
| 薪资与个税 | 员工、算薪、社保、计提发放凭证 | PRD 标为 V1.2，实际可前移为已交付 |
| 反结账 | 守卫 + 事务回滚 + 日记账期初恢复 | 写入结账章节 |
| 会计准则双模板 + 报表规则可配置 | 建账复制 + rules 种子 | 写入基础设置亮点 |
| 凭证录入工作台（留页/邻证/WYSIWYG） | OpenSpec 已完成 | 更新凭证原型说明 |
| 经营仪表盘指标集 | 资金/应收/利润/增值税等 | 明确是否替代「老板极简报表」 |
| 机构（institutions）域名品牌 | 配置页 + Filter | PRD 标注为部署项，非完整多租户 |

## 11. 优先级汇总（缺口补齐建议）

### P0（代账合规与交付刚需）

1. ~~往来管理最小闭环（余额/明细/对账/账龄）~~ → **已落地 L1+L2**；剩余 **核销 L3** 见 P1  
2. **账套/数据备份与恢复**（至少手动导出备份包 + 恢复演练）  
3. **本月账本包 ZIP**（对齐 `openspec/changes/daizhang-commercial-plan`）

### P1（体验与合规打磨）

1. **往来核销 L3**（开项匹配）  
2. 明细账凭证号溯源；报表关键数字下钻（可选）  
3. 经典凭证打印模板接入生产入口  
4. 制单人 ≠ 审核人；往期锁定补齐新建凭证  
5. 首页待办；业务操作日志 + IP  
6. 凭证附件文件；老板报表定位确认（看板 vs 独立页）  
7. 账套封存态（或强化结账锁的产品表达）

### P2（增强）

1. 多栏账 / 数量金额账  
2. 资产盘点  
3. PDF 导出与打印统一  
4. 作废/拒绝状态机产品化  
5. 银行调节、费用报销、税务申报（对接 PRD V1.1+）

## 12. 覆盖率粗估（相对 PRD V1.0 八大模块）

| 模块 | 粗估覆盖 |
|------|----------|
| 账套 | ~60% |
| 基础设置 | ~85% |
| 凭证 | ~75% |
| 账簿 | ~70% |
| 固定资产 | ~80% |
| 往来 | ~70%（L1+L2；核销 L3 未做） |
| 报表 | ~70% |
| 系统 | ~65% |

**整体**：主做账闭环可商用打磨；**备份与账本包、核销 L3** 仍是相对 PRD 的主要断层；往来 L1+L2 与薪资/日记账/反结账已超出部分 PRD 文本预期。

详细模块说明见 [01](01-account-book.md)～[11](11-arap.md)；路线见 [21-roadmap.md](21-roadmap.md)。
