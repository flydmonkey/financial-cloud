## Why

小企业自营发薪场景需要「算得清社保 → 调得动加减项 → 进得了账 → 付得出钱」的最小闭环。现有薪资模块已具备员工档案、按人缴费基数字段、算薪临时表、计提/发放凭证与工资表导出，但算薪流程分散、按人基数/险种规则产品化不完整，且缺少银行代发盘，财务仍无法在系统内完成真实发薪动作。

## What Changes

- **按人社保公积金基数产品化**：明确员工级统一基数与账套默认基数的优先级；补齐校验与算薪结果可见性；对已有但未生效的分险种自定义规则给出可用行为（或明确本期仅支持统一基数）。
- **当月算薪引导闭环**：把「选所属月 → 生成预览 → 调整应增应扣 → 推送明细 → 生成计提/发放凭证」收敛为可跟完的引导路径，降低跳页与漏步骤。
- **银行代发盘导出**：基于已确认工资明细（实发 + 银行卡信息）导出通用代发盘（CSV/Excel），支撑线下网银批量支付。
- **择一决策（已定）**：本期交付**银行代发盘**，**不做工资条/员工自助**。
- **Non-goals**：综合所得累计预扣法纠偏（另案）、自然人电子税务局申报对接、费用报销、多薪资结构可视化大改。

## Capabilities

### New Capabilities

- `payroll-smb`: 小企业发薪最小闭环——按人社保基数生效与可见、当月算薪引导路径、银行代发盘导出。

### Modified Capabilities

- （无；`openspec/specs/` 下尚无既有薪资 capability。）

## Impact

- **后端**：`Employee` / `EmployeeSalaryTempService` 基数规则与校验；工资明细/汇总导出代发盘 API；必要时扩展 DTO。
- **前端**：员工社保基数表单与提示；`calc-salary` / 明细 / 汇总页引导与代发盘入口。
- **文档**：`docs/product/09-payroll.md` 更新小企业闭环与边界。
- **测试**：基数规则单测；代发盘字段/校验单测或 API 测；算薪引导 E2E/smoke。
