# 固定资产清理凭证（A1）

## 范围

在现有「清理」入口上扩展：弹窗录入处置收入/清理费用/科目，生成 **一张** 清理凭证，再置 `DISPOSED`。

## 凭证分录

1. 借：累计折旧、减值准备、固定资产清理（账面价值）；贷：固定资产（原值）
2. 有收入：借对方科目，贷清理
3. 有费用：借清理，贷对方科目
4. 结转：余额>0 → 借营业外支出，贷清理；余额<0 → 借清理，贷营业外收入

科目默认：清理 `1606`/`1701`；收益 `5301.01`/`5301`；损失 `5711.02`/`5711`/`5601`；对方 `1002`/`1001`。卡片已配置科目优先。

## 落库

- `fixed_asset.status=DISPOSED`、`disposed_period=当前期`、`dispose_voucher_id`
- 自动写变动记录「资产清理」
- 清理当月仍计提、次月停提（既有规则不变）
