# 21 · 迭代路线建议

> **当前优先方向（2026-10-02）**：先落实账务可信和使用顺畅。交付独立手算案例、隔离验收工具、首页做账指引、月结处理建议及已结期间交付；随后安排真实会计试用。主要功能已实现，不以历史 P0/P1 清零认定已完成生产交付。完整附件备份另行排期，本轮不扩展模块。

> 目标：在**代码现状**与外部 PRD 之间找可交付路径。  
> 主轴对齐 OpenSpec「代账商业化总规划」：`交付包 → 打印与吞吐 → 资金往来 → 周边卫生`。  
> 同时映射 PRD 的 V1.1（税务）/ V1.2（薪酬票据）/ V1.3（移动+AI）。
