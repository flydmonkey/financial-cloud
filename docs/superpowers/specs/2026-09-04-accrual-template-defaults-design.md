# 计提凭证模板按会计制度自动填充默认分录

**状态：** 已实现  
**日期：** 2026-09-04  
**范围：** 3 个计提模板（`jt_fjs` / `jt_gz` / `jt_sds`；不含结转）

## 背景

期末处理页的计提模板（`jt_fjs` / `jt_gz` / `jt_sds`）从会计准则标准库复制到账套时，标准库分录多为空，导致新建账套后模板无科目骨架，用户需手工「+」配置。`jt_zj`（计提折旧）已退役，改由固定资产模块计提；`qm_jz_xscb` 已并入 `qm_jz_cbfy`。

收入/成本结转（`qm_jz_sr` / `qm_jz_cbfy`）已按 `standardId` 在建账时补默认分录；本变更将同一机制扩展到上述计提模板。

## 目标

1. 创建账套并选择会计制度后，三个计提模板自动写入与制度匹配的默认分录。
2. 已有非空分录不覆盖（幂等、可编辑）。
3. 不改结转类模板生成逻辑；固定资产折旧仅走固定资产模块。

## 非目标

- 不为 `qm_jz_sds` / `qm_jz_bnlr` 等结转模板补默认（另议）。
- 不在本轮做「已有账套一键修复」管理界面（可选后续 SQL/接口）。
- 不按部门/费用多科目拆分工资（默认全部进管理费用）。

## 方案

**方案 B：** 代码内按 `standardId` 定义默认分录规格；`insertBookTemplate` 复制后若目标模板分录为空则补齐。退役码（`jt_zj` / `qm_jz_xscb`）不复制。

### 默认分录规格

| 模板编码 | 小企业会计准则 (`1`) | 企业会计制度 (`2`) |
|----------|----------------------|---------------------|
| `jt_gz` 计提工资 | 借 `5602.07` / 贷 `2211.01`（末级；旧父级 `5602`/`2211` 在生成凭证时仍会解析到末级） | 借 `5502` / 贷 `2151`（生成时解析末级） |
| `jt_sds` 计提所得税 | 借 `5801` / 贷 `2221.05` | 借 `5701` / 贷 `2171.06` |
| `jt_fjs` 计提附加税 | 借 `5403` / 贷 `2221` | 借 `5402` / 贷 `2171` |

方向约定：`1`=借，`2`=贷。摘要取模板业务名。

### 实现落点

1. **`MonthEndCloseRules`** — `defaultAccrualTemplateItems` / `isRetiredTemplateCode`
2. **`VoucherTemplateService.insertBookTemplate`** — 跳过退役码；空计提模板补默认分录
3. **建账入口** — `BookService.save` → `insertBookTemplate`
4. **测试** — `MonthEndCloseRulesTest`

### 行为边界

| 场景 | 行为 |
|------|------|
| 标准库已有分录 | 原样复制到账套，不覆盖 |
| 标准库为空 | 按制度生成默认分录 |
| 账套模板已有分录 | `ensure*` 跳过 |
| 退役码 | 软删 + 建账不复制 |

## 验收

1. 新建小企业/企业制度账套：三个计提模板各有 2 条分录。  
2. 列表不再出现 `jt_zj`。  
3. 相关单元测试通过。

## 风险与说明

- 所得税对方科目用明细码（`2221.05` / `2171.06`）；若科目树未启用该明细，可在模板编辑中改父级。
