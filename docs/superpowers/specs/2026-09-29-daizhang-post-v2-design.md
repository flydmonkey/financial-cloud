# 代账吞吐 Post-V2 · 产品设计规格

> Date: 2026-09-29  
> Status: **completed**（接续吞吐 V2；用户授权全权自主）  
> Related: [吞吐 V2](2026-09-29-daizhang-throughput-v2-design.md)、[backlog](../plans/2026-09-29-throughput-v2-backlog.md)

## 1. 背景

吞吐 V2（W0–W4）已收口。剩余高频摩擦中，**凭证状态机下的改证路径**仍是代账日常误操作点：列表「修改」可进编辑态，分录格仍可点，但保存被静默禁用；后端仅返回笼统拒绝。

本程序不扩新业务域，只收口改证路径 + 文档/仪表盘。

## 2. 目标与成功标准

1. 已过账 / 已审核 / 审核中凭证在编辑页只读，并给出可行动提示。
2. 列表「修改」对上述状态走只读。
3. 后端修改拒绝文案可区分：已过账 / 已审核 / 审核中 / 已作废 / 已结账期间。
4. 有前端单元测试 + 后端断言；文档与质量仪表盘同步。

## 3. Non-goals

- 过账后直接改分录并自动回写账簿（禁止）
- 按钮级权限全站铺开
- TypeScript / ESLint 存量清零（仍质量债；本程序仅修本刀引入的回归）
- 银行余额调节 / 税费向导增强
