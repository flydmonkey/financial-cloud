## Context

工资发放生成已自动补齐模板，但回归仍接受缺模板失败。附件二进制位于 file_storage.data_stored；当前 v1 恢复通过源引用查本实例文件并验证来源管理员。

## Decisions

- 用单独的固定账期测试账套核对工资应发、扣款、实发；两张凭证必须生成、过账和影响账簿，重复生成必须拒绝。
- 试账材料提供匿名化输入、旧系统与本系统对照、差异处理及签字状态；不伪造真实会计审阅。
- v2 ZIP 使用 files/<序号>.bin 与 manifest.files 的原 file id、白名单元信息、长度及 sha256。附件引用必须与声明完整匹配。恢复插入新文件 id，所有附件只关联新文件；v1 保留既有来源权限验证。
- 在解析阶段完成表与附件校验，恢复文件写入与业务写入在同一数据库事务；坏包不创建账套。ZIP 拒绝路径穿越、重复项和超限解压（单项 32 MiB、总计 128 MiB、最多 10000 项），导出遵循同样限制。
- 不引入新依赖或真实库迁移；新包旧服务无法读，回滚前需要保留支持 v2 的恢复工具。

## Validation

工资独立固定金额与账簿增量、文件内容；v2 导出/无来源恢复、v1 权限、损坏校验、重复 ZIP 与资源上限；真实隔离库删除源文件后恢复并核对报表与附件，删除恢复附件不影响源。
