# 记账凭证打印 · 经典国标风设计

日期：2026-09-02  
状态：已确认（待实现）  
参考样张：`docs/voucher-print-preview-classic.html`

## 目标

将凭证打印页改为专业、可读的经典国标风格，固定每页分录行数，并在分录超过一页容量时按「续页」分页打印——不拆业务凭证号。

## 范围

**纳入**

- 打印模式（`voucher-edit` 在 `mode=print` / 临时打印路由）的版式与样式
- 每页 6 行分录、C5 横向、合计大写、备注入表、续页规则
- 现有金额转中文大写能力的复用（`voucher-edit.vue` 已有转换函数）

**不纳入**

- 编辑态录入 UI 大改
- 凭证业务模板内容变更（科目体系、审核流等）
- 服务端生成 PDF
- 将一张业务凭证拆成多个凭证号

## 纸张与居中

| 项 | 约定 |
|----|------|
| 纸张 | **C5 横向**（229mm × 162mm）；也可用 **B5 横向** |
| `@page` | 默认 C5；打印对话框可选 C5/B5；边距选「无」 |
| 居中/铺满 | 打印时凭证铺满当前纸张可打印区域 |

屏幕预览按 C5 尺寸（229×162mm）展示第一版国标卡片风；**不以 A5 为准**。

## 单页版式

自上而下：

1. **标题**：居中「记账凭证」（字距补偿，视觉居中）
2. **日期**：居中，形如 `YYYY 年 MM 月 DD 日`
3. **元信息行**：左「核算单位：…」；右「{字} {号}」与「附件 n 张」
4. **分录表**（见下）
5. **签名行**（仅末页）：会计主管 / 过账 / 复核 / 制单

### 分录表列

| 列 | 说明 |
|----|------|
| 摘要 | 左对齐 |
| 会计科目 | 科目编码+名称；辅助核算另起一行小号字 |
| 借方金额 | 右对齐，千分位 |
| 贷方金额 | 右对齐，千分位 |
| 行次 | 居中；跨页时按凭证内连续编号（1…N），不每页重置 |

### 每页行数

- 固定 **6 行**分录位。
- 实际分录不足 6 行时，用空行补足到 6，保持版心高度稳定。
- 空行不显示金额，行次仍占位显示（或仅对有内容行编号——实现时统一为：**有内容行连续编号，空行行次空白**；跨页续行接续编号）。

### 表尾（仅末页）

1. **合计行**
   - 左：「合　计」
   - 科目列位置：「人民币（大写）」+ 中文大写金额（借方合计绝对值，借贷平衡时用同一合计额）
   - 借方合计、贷方合计数字
2. **备注行**
   - 左：「备　注」
   - 右侧合并单元格展示凭证备注；无备注可留空行占位

中间页、非末页：**不渲染**合计行、备注行、签名行。

## 续页规则（分录 > 6）

采用方案 **A · 续页**（已确认）：

| 规则 | 说明 |
|------|------|
| 业务身份 | 所有页共用同一凭证字号；**不**生成新凭证 |
| 分页 | `ceil(有效分录数 / 6)` 页；每页最多 6 条有效分录 |
| 首页标题 | 「记账凭证」 |
| 续页标题 | 「记账凭证（续）」 |
| 页码 | 各页右上或元信息区标注「第 n / 共 m 页」（仅 m>1 时显示） |
| 合计 / 大写 / 备注 / 签名 | **仅末页** |
| 非末页表体 | 仅表头 + 最多 6 行分录（可含为满版而补的空行，空行仅出现在该页有效分录之后） |

示例：14 条有效分录 → 3 页（6 + 6 + 2，末页再补 4 空行至 6）。

## 视觉风格

- 宋体系正文（`Songti SC` / `SimSun` 等），数字等宽表格感
- 双线标题底边、细黑表格线、浅米色表头底
- 不做卡片化、不做彩色强调条；打印以黑白清晰为准

参考实现样张：`docs/voucher-print-preview-classic.html`（实现前可按本规格补一页「续页」示意，非必须）。

## 数据与边界

- **有效分录**：打印前过滤无科目的空录入行（与现有 print 过滤逻辑一致）。
- **0 条有效分录**：仍打 1 页，6 空行 + 末页合计（0）与签名。
- **大写**：借贷不平衡时仍按借方合计转大写，并保持现有业务校验不在打印环节重复拦截（编辑保存已校验）。
- **附件张数 / 审核人等**：沿用表单已有字段；缺省显示为空线下划线位。

## 测试要点

1. ≤6 行：单页，含合计大写、备注、签名；行数视觉为 6。
2. 7–12 行：2 页；首页无合计；末页有合计；同号；页码 1/2、2/2。
3. 13+ 行：多页；行次跨页连续。
4. 打印预览：C5 横向下内容居中，不偏左、不顶头贴边。
5. 回归：非 print 编辑态行为不变。

## 验收标准

- 打印视觉符合经典样张节奏，C5 横向可用。
- 超过 6 行自动续页，凭证号不变。
- 合计、人民币大写、备注、签名仅出现在最后一页。
- 不引入第二张业务凭证。
